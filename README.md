## 🔍 درباره پروژه (Overview)
این پکیج یک ماژول امنیتی و آموزشی برای بررسی، شناسایی و ایمن‌سازی آسیب‌پذیری‌های نوع **RCE (Remote Code Execution)** و تبدیل ناخواسته فایل به شل در زبان PHP (`php2shell`) است. هدف این مخزن ارائه راهکار دفاعی و نمونه کدهای اصلاح‌شده است.

---

## 📂 ساختار مخزن (Repository Structure)
* **`/images`** ⬅️ تصاویر مستندات، اسکرین‌شات‌ها و دیاگرام‌ها
* **`/src`** ⬅️ کدهای سورس اصلی
  * `vulnerable.php` ⬅️ نسخه آسیب‌پذیر (برای تست و تحلیل)
  * `secure_patched.php` ⬅️ نسخه ایمن‌سازی شده (پچ شده)

---

## 🛠️ نحوه استفاده (Usage)
لطفاً برای بررسی کدهای مخرب و نحوه ایمن‌سازی، به پوشه `src` مراجعه کرده و مستندات موجود در تصاویر را بررسی کنید.
